Transmission Lab 1.3.0
자동차 변속기 해부 · 체험·실험 앱

1. 시작과 구조 관찰
바탕화면 또는 시작 메뉴의 Transmission Lab 아이콘을 클릭합니다.
위쪽에서 MT · DCT · CVT · AT · eCVT를 고릅니다.
마우스로 회전하고 휠로 확대·축소합니다. 부품을 클릭하면 설명이 열립니다.
이름표는 회전 부품을 따라 돌지 않습니다.

절개: 케이스 벽 일부를 열어 내부 조립을 봅니다.
외형: 전체 케이스를 표시합니다.
내부만: 케이스를 숨겨 동력 연결을 봅니다.
절개 범위와 부품 벌리기로 관찰 공간을 조절합니다.
기어 · 클러치 · 베어링 · 윤활 분류와 구성 요소 표시를 이용합니다.
오일 흐름은 윤활 경로의 개념 표시이며 실제 유량·유압·유온을 계산하지 않습니다.

2. 크게 보기와 화질
3D 옆의 크게 보기 또는 F를 누르면 장면을 확대합니다.
Escape나 작게 보기로 돌아옵니다. 운전 조건과 부품 선택은 유지합니다.
화질에서 자동 · 정밀 · 균형 · 가볍게를 선택합니다.
화질은 표현에 사용하는 면 수와 렌더링을 조절하며 계산 RPM·토크·부품 구성은 바꾸지 않습니다.
작은 화면에서는 왼쪽 운전 조건과 오른쪽 부품 목록을 각각 스크롤합니다.
그래프 접기/펼치기로 장면을 볼 공간을 조절할 수 있습니다.

3. 운전 조건과 자동 실험
입력 회전수·토크·기어 또는 변속비를 바꾸고 출력 수치를 읽습니다.
MT·DCT는 기어와 클러치, CVT는 풀리 비율, AT는 유성기어 연결과 컨버터,
eCVT는 MG1 회전수와 MG2 토크로 대표 작동 원리를 살펴봅니다.

장면 옆의 자동 실험을 누르면 해당 형식의 조건을 자동으로 바꿉니다.
중간에 운전 조건을 직접 조절하면 자동 실험이 멈춥니다.
완료하면 일시정지하고 실제 실험 전·후의 회전수·토크·기어비를 표시합니다.
최근 자동 실험 1건의 전후 결과를 보관하며 결과 보기로 다시 확인합니다.
전후 비교에 추가를 누르면 두 결과를 조건 비교 표에 넣습니다.
엔진 회전수 0인 경우 정지 조건 안내를 확인하고, 입력 회전수를 높여 다시 관찰해 보세요.
자동 실험은 특정 차량의 성능 시험이나 주행 제어를 재현하는 기능이 아닙니다.

Space: 재생·일시정지
↑ / ↓: 지원하는 기어를 위·아래로 변경
F / Escape: 크게 보기·돌아오기
F11: 앱 전체 화면
Ctrl+O / Ctrl+S: 프로젝트 열기·저장
Ctrl+R: 실험 초기화

회전 표시는 보기 쉽게 느리게 합니다. 계산 수치와 실험 시간은 회전 표시 속도와 구분됩니다.
화면이 오래 지연되면 실험을 일시정지했다는 안내를 표시합니다.
이 안내가 나타나면 재생을 눌러 이어가십시오.

4. 순간 결과 비교
그래프 옆의 조건 비교는 누른 순간의 입력 조건과 계산값을 함께 보관합니다.
DCT 변속 중에도 저장한 순간 결과를 유지하며 자동으로 완료 상태로 다시 계산하지 않습니다.
비교는 최대 4개입니다. 공간이 부족하면 먼저 필요한 결과를 백업하고 비교 표에서 삭제하십시오.
새 결과를 추가하기 위해 기존 결과를 자동으로 버리지 않습니다.
조건 적용은 해당 조건으로 새 실험을 시작합니다. 저장했던 순간 결과와 구분해서 읽습니다.
비교표 CSV 저장으로 수치·단위·기록 시간과 결과 출처를 내보냅니다.

5. 저장과 원문 보관
운전 조건·관찰 설정·비교 결과·최근 자동 실험 결과를 앱 저장소에 자동 보관합니다.
프로젝트 저장은 이 내용을 JSON 파일로 백업합니다.
파일 > 프로젝트 열기로 불러오며 잘못되거나 지원하지 않는 형식은 현재 작업을 바꾸지 않습니다.
프로젝트 형식 v2는 저장 당시 비교값과 자동 실험 전후 결과를 함께 보관합니다.
계산값 없이 조건만 저장한 이전 형식은 '조건으로 재계산'이라고 표시합니다.
이전 반투명 케이스 설정은 조립 절개로 준비하며 케이스 숨김 설정은 유지합니다.

손상되었거나 현재 앱이 지원하지 않는 자동 저장 원문이 있으면 저장 복구를 확인하십시오.
저장 복구 > 원문 파일 저장으로 이전 내용을 따로 보관할 수 있습니다.
원문 파일을 내려받는 동작이 지원하지 않는 데이터를 현재 프로젝트로 복원한다는 뜻은 아닙니다.
저장 공간 부족·자동 저장 실패 안내가 나오면 앱을 닫기 전에 프로젝트 파일을 저장하십시오.
메모리에만 있는 새 작업은 종료 후 유지되지 않을 수 있습니다.

저장 폴더는 도움말 > 저장 폴더 열기에서 확인합니다.
기본 위치: %APPDATA%\Transmission Lab
Suspension Lab의 저장 폴더와 분리됩니다.
업데이트 전 프로젝트 파일을 백업하고 앱을 종료한 뒤 새 설치 파일을 실행합니다.
일반 제거는 자동 저장한 사용자 데이터 폴더를 삭제하지 않습니다.

6. 모델 범위·오프라인·도움말
Windows x64와 WebGL 2를 지원하는 그래픽 환경을 대상으로 합니다.
실행 환경과 3D 라이브러리를 설치본에 포함하며 별도 Node.js·서버가 필요하지 않습니다.
이 앱은 대표 구조와 일정한 입력 회전수를 가정한 운동학·동력 관계를 설명합니다.
제조사별 원본 사진·CAD나 실차 정비 조립도를 제공하지 않습니다.
AT는 단일 유성기어의 네 연결 원리 모드입니다. 특정 양산 4단·8단 기어박스의 복제가 아닙니다.
eCVT는 유성기어 동력 분할이며 벨트 CVT와 다릅니다.
eCVT 배터리 양수는 방전, 음수는 충전입니다. 잔량·전압·전류·모터 운전 한계는 계산하지 않습니다.
주행 역학·변속 충격·치면 접촉·유압·열·부품 수명 해석은 포함하지 않습니다.
