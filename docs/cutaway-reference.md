## 조립 형상을 판단하는 기준

- 기본 화면은 축·기어·베어링·클러치가 케이스 안에 모인 조립 절개 상태다. 분해도는 사용자가 선택하는 별도 관찰 상태다.
- 케이스를 단순 반투명 상자로 대신하지 않는다. 주조 리브, 플랜지, 베어링 지지 보스, 오일팬 접합부와 실제 벽 두께를 가진 절개 창을 표시한다. 절개면은 남아 있는 외벽·내벽 사이의 단면이며 빈 창을 덮는 판이 아니다.
- 주조 알루미늄은 회색의 거친 표면, 축·치면·베어링은 가공 강철, 마찰재·씰은 어두운 표면, 모터 권선은 구리색으로 구분한다. 선택 색과 동력 흐름은 재질을 알아볼 수 있는 약한 보조 표시다.
- DCT는 입구 쪽 짧은 B 중공축의 2·4·6/R과 그 끝을 지나가는 긴 A 내측축의 1·3·5를 조립 가능한 위치에 둔다. 축방향 위치 변경은 기어 ID·잇수·RPM·모델의 홀수/짝수 연결을 바꾸지 않는다.
- 외접 평행축 기어의 중심 거리와 피치 반지름, 후진 아이들러의 두 맞물림, 유성기어의 공전 반지름을 유지한다. 헬리컬 표현을 사용하는 외접 평행축 쌍은 반대 나선 방향, 링과 플래닛의 내접 쌍은 같은 나선 방향이다. 치형 접촉·축방향 하중을 해석하는 모델은 아니다.
- 건식 MT의 마찰 디스크는 변속기 입력축에, 압력판과 다이어프램은 엔진 측에 연결한다. 건식 클러치 공간과 기어 오일 섬프를 구분한다. 습식 DCT는 드럼과 철제 판을 엔진 측, 마찰판을 해당 A/B 축 측에 연결한다.
- 베어링 내륜은 실제 지지 축의 RPM, 케이스 측 외륜·축 씰은 0 RPM이다. 모터의 스테이터·권선도 케이스에 고정되고 로터만 해당 모터 RPM으로 돈다. 케이스와 절개면은 회전하지 않는다.
- CVT 풀리 피스톤은 가동 sheave와 함께 이동한다. 벨트가 닿는 반지름과 기존 고정 길이 계산을 장식용 위치로 교체하지 않는다.
- AT의 유성 직결 팩은 원리 3단에서 결합하며 토크컨버터 잠금과 구분한다. eCVT에 변속 클러치·변속용 밸브바디를 추가하지 않는다.

## 원리 모형을 유지하는 범위

[Toyota THS-II 공식 설명](https://global.toyota/en/powertrain/ths/)은 후대 MG1·MG2의 다축 구조와 별도 감속 배치를 보여 준다. 현재 앱은 초기 입력분할 대표 구조처럼 엔진=캐리어, MG1=선기어, MG2/출력=링기어의 연결을 사용하므로 외형 참조만으로 이 연결을 바꾸지 않는다. 모든 하이브리드가 클러치 없는 구조라는 뜻도 아니다. 위 공식 페이지의 멀티스테이지·PHV 변형은 앱이 선택한 기본 eCVT와 구분한다.

기어·클러치의 수치와 동력 수지, 고정 길이 CVT, 유성 구속식은 [model.md](model.md)에 명시한 값을 유지한다. 오일 흐름과 작동부 형상은 윤활·냉각의 개념 표시다. 표시 입자 속도, 케이스 절개 정도, 분해 간격은 실제 유량·압력·열·공차를 뜻하지 않는다.

장면 수정 후 축 연결·회전 키·고정부와 절개면을 별도로 읽어 검토한다. 공식 사진 확인은 제품의 외형 참조이며 특정 생산 변속기를 정확하게 재현했다는 검증으로 사용하지 않는다.

## 독립 형상 검증

`tests/geometry.test.mjs`의 11개 검사가 통과했다. 렌더러의 메타데이터 표시만 믿지 않고 실제 좌표·법선·UV·삼각형 면적, 좌표로 접합한 면의 닫힘과 winding, 광선과 축 구멍의 교차 여부를 검사한다. 다섯 케이스의 절개 0/1 끝값 및 0.2/0.8 형상 변화, 닫힌 덮개의 실체, 숨김의 가시 삼각형 0, 반복 조작 시 버퍼 해제와 개수 유지를 확인한다. 기어는 헬리컬 층의 실제 비틀림·반대 나선의 대칭·중앙 통로와 허브 스플라인을 확인한다.

추가한 닫힌 MT·DCT 검사는 생성된 주기어 치끝 반경을 실제 축방향 앞·중앙·뒤 단면에서 96방향으로 회전시켜 케이스 내벽 삼각형까지의 광선 교차 거리를 확인한다. 처음 발견된 하단 1단 기어와 케이스 곡면의 겹침은 내부 공간을 넓혀 해결했고, 모든 주기어가 표시 좌표 기준 0.02 이상 떨어지는 것을 확인했다. 모델 검사 24개를 포함한 전체 검증 수는 35개다. 이 간극은 화면 조립 검사의 기준이며 실제 제조 공차가 아니다.

최종 읽기 검토에서도 MT 건식 디스크의 입력축 연결, 습식 DCT의 공통 드럼·독립 A/B 축·변속 슬리브 방향, CVT 피스톤·풀리·베어링의 동축, 유성기어 중공축과 캐리어 허브의 개방 통로, 고정 절개 드럼과 회전 링, 모터의 고정 스테이터와 회전 로터를 확인했다. AT의 유성 직결 팩과 컨버터 잠금은 구분되고, eCVT에 변속 클러치를 넣지 않았다. 검토 완료 상태는 STABLE이다. 이 검증은 형상과 자원 관리에 대한 검사이며 실제 치형 접촉·제조 공차·강도를 검증하지 않는다.
