# 일반 체험·실험용 제품 평가

대상 버전: **1.3.0**. 평가 대상은 자동차 변속기의 대표 구조와 동력 연결을 관찰하는 Windows 앱입니다. 제조 공차·내구·열·실차 설계 또는 정비를 검증하는 도구로 평가하지 않습니다.

**1.3.0 일반 체험용 기술 평가 통과.** 소스·독립 실행 EXE·설치 파일 대조·실제 설치와 기존 설치본 업데이트를 확인했습니다. 배포 위치는 [Releases](https://github.com/Ulsancl/transmission-lab/releases)이며 설치 파일의 실제 제공 여부는 해당 페이지에서 확인합니다. 기술 평가와 유료 판매 개시는 별도입니다.

소스·독립 앱과 설치 실행 검사의 수집 오류·외부 콘텐츠 요청은 0입니다. 데이터 확인에는 이전 시험 프로필의 사본을 사용해 실제 사용자 AppData 내용을 수정하지 않았습니다. 설정·표시 옵션과 저장 결과를 유지하고, 설치된 실행 내용이 시험한 배포 내용과 같으며, 두 번째 실행이 기존 창 하나를 재사용하는 것을 확인했습니다. 바탕화면·시작 메뉴의 1.3.0 대상도 확인했습니다. 실제 설치 파일 서명은 `NotSigned`이며 파일 확인에는 동명 `.sha256`을 사용합니다. 설치 파일의 해시·바이트 수는 이 문서에 고정하지 않습니다.

소비자 회귀는 DCT 과도 중 순간값의 프로젝트 v2 보존·재실행, 비교 4개 한도와 원자적 거부, 다섯 자동 실험의 실제 전후 결과·0 rpm 안내, 작은 화면·집중 보기 복원·화질별 계산값 유지와 저장 공간 실패 시 프로젝트 백업을 확인합니다. 장면 검사는 헤드리스 Chromium·ANGLE SwiftShader 환경입니다. 그 환경의 부하 측정을 사용자의 실제 GPU FPS로 해석하지 않습니다.

구현한 개선에는 저장 당시 계산값의 유지, 자동 실험의 실제 전후 비교, 손상 저장 데이터의 원본 보존과 실행 시간의 화면 회전 속도 독립성이 포함됩니다. `tests/project.test.mjs`를 기존 모델·형상 단위 검사와 함께 실행하며, UI·재실행·독립 배포본에서도 연결을 별도로 확인합니다. 구버전의 조건만 있는 비교 기록은 현재 모델에서 재구성한 결과로 명시합니다.

### 이전 버전 1.2.0

수치 모델 24개, 실제 기하 11개, 웹 화면 23개, 소스 데스크톱 14개, 독립 실행 배포본 14개로 총 **86개** 검증이 통과했습니다. 다섯 구조, 케이스 벽 두께와 절개 창, 헬리컬 기어·중앙축 통로·조립 여유, 관찰 방식의 저장·재실행 유지와 1.0·1.1 설정 복원을 검사했습니다. 소스와 독립 배포본의 검사에는 앱 오류·외부 요청 0이 기록되어 있습니다. 이는 이전 버전의 구현 검사 기록이며 1.3.0 판정에 그대로 대입하지 않습니다.

## 현재 제공 범위

Windows x64 설치 앱과 소스를 제공합니다. 설치 앱은 첫 실행부터 오프라인으로 작동하고 앱 저장 공간을 사용합니다. 원본 제조사 사진·CAD는 포함하지 않습니다. 대표 구조의 원리 모델이며 실제 차종별 조립도, 치면 접촉, 변속 충격, 유압·열·모터 한계나 배터리 잔량을 해석하지 않습니다. 상세 범위는 [모델 설명](model.md)에 있습니다.

디지털 서명과 자동 업데이트는 없습니다. 새 버전 설치로 갱신하며 프로젝트 JSON으로 사용자가 설정을 백업할 수 있습니다. 일반 체험용 기술 평가와 유료 판매 개시는 별도 상태입니다. 가격·구매 경로·지원 기간·환불 조건을 이 기술 평가 문서가 정하지 않으며 판매 계약이나 차량 안전 승인을 제공하지 않습니다. 앱 자체의 기존 **UNLICENSED** 권리 유보 상태를 유지합니다.

## 공개 자료의 구성

저장소에는 소스·lockfile·테스트·빌드 설정·설명 문서와 앱 자체의 선별 대표 화면만 포함합니다. 사용자별 설치 경로·시험 프로필·원본 QA 로그가 들어 있는 `output/`, 실행 파일과 의존성 폴더는 제외합니다. 설치 프로그램과 동명 SHA-256 파일의 배포 위치는 [Releases](https://github.com/Ulsancl/transmission-lab/releases)입니다. 실제 제공 파일과 원격 실행 상태는 릴리스와 Actions 페이지에서 확인합니다. CI 아티팩트는 설치 프로그램과 SHA-256으로 제한하며 릴리스 게시를 자동 수행하지 않습니다.
