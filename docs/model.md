# Transmission Lab 계산 모델

이 앱은 자동차 변속기의 대표 구조를 분해해 보는 **정속·준정적 작동 원리 실험**입니다. 사용자가 입력 회전수와 토크를 지정하면 기어 구속식, 클러치 상태, 풀리 접촉 반지름, 모터 전력 수지를 계산합니다. 차량 질량·축 관성·차동기어·종감속비·타이어·실제 변속 제어·열·파손 한계는 포함하지 않습니다. 분해 간격은 관찰을 위한 배치 변화이며, 회전 계산은 조립 상태의 연결을 유지합니다.

## 공통 수치와 표시

- RPM은 각 축의 +x 방향에 대한 오른손 회전을 양수로 표시합니다.
- 감속비 `i`는 원칙적으로 기어 입력 RPM ÷ 출력 RPM입니다. 음수는 반대 회전입니다. 정의할 수 없는 중립·eCVT 출력 정지에서는 0을 사용합니다.
- 축 동력은 `P[kW] = T[N·m] × RPM × 2π / 60000`입니다. 출력 토크와 출력 RPM이 모두 음수인 후진도 구동 동력은 양수입니다.
- 사용자가 지정하는 효율은 부품 데이터가 아닌 예시 기계 효율입니다. 기본 96%, 설정 범위 70–100%입니다.
- 일반 모드에서 `입력 동력 − 출력 동력 = 클러치/컨버터 슬립 손실 + 기계 손실`입니다. eCVT에서는 모터·인버터 손실도 더합니다.
- 엔진 토크 명령은 일정 속도 구동원이 내는 전달 토크의 기준입니다. 중립에서는 부하가 없는 것으로 두어 실제 입력 토크와 전달 동력은 0입니다. 엔진은 계속 회전할 수 있습니다.
- 앱의 느린 재생 속도는 화면의 회전만 늦춥니다. RPM·토크·동력 계산에는 적용하지 않습니다.

## MT · 수동

여섯 개 기어 쌍의 입력/피동 톱니 수는 18/62, 24/56, 30/50, 36/44, 42/38, 46/34입니다. 같은 모듈과 톱니 수 합 80으로 같은 축간 거리를 유지합니다. 외접 기어 맞물림은 회전을 반전합니다. 대표 최종 전달 기어를 1:1로 한 번 더 맞물려 최종 출력을 양의 전진 방향으로 표시합니다. 양산 차량의 종감속비를 재현한 값은 아닙니다.

상시 맞물리는 피동 기어는 입력 기어의 속도로 계속 회전합니다. 선택된 피동 기어만 선택 슬리브를 통해 출력축에 잠깁니다. 후진은 18T 아이들러를 추가해 최종 출력 방향을 바꿉니다. 아이들러의 톱니 수는 최종 비율을 바꾸지 않습니다.

클러치 제어값 `c`는 0–1입니다. 원리 관찰을 위해 `기어 입력 RPM = c × 엔진 RPM`, `전달 엔진 토크 = c × 토크 명령`을 동시에 지정합니다. 중간 값은 정속 구동원·제어 클러치가 유지하는 회전차이며, 실제 페달 위치로부터 마찰 토크를 예측하는 모델은 아닙니다. 전달 엔진 토크 `T`에 대해 슬립 손실은 `T × (엔진 각속도 − 기어 입력 각속도)`입니다. 남은 동력에 기계 효율을 적용합니다. 클러치를 완전히 열면 무관성 출력은 정지하며 실제 차량의 관성 주행을 뜻하지 않습니다.

## DCT · 듀얼 클러치

홀수 1·3·5단은 A축, 짝수 2·4·6단과 후진은 B축입니다. 각 축의 선택된 기어가 공통 피동축에 연결됩니다. 반대 클러치가 열려 있어도 미리 선택된 기어를 통해 출력이 그 입력축을 역구동합니다. 따라서 `분리된 입력축 RPM = 출력 RPM × 미리 선택된 기어 감속비`이며, 분리된 축을 임의로 정지시키지 않습니다.

다른 축으로 변속할 때 0.85초 동안 A/B 토크 용량이 선형 교대합니다. 서로 다른 두 감속비를 동시에 완전 직결할 수 없으므로, 교대 중 출력 속도는 이전/새 기어 중 낮은 출력 속도 명령을 유지합니다. 두 클러치의 회전차와 손실을 개별 계산합니다. 완료 후 새 정속 출력 명령을 적용합니다. 이 시점의 속도 변화는 차량 가속 해석이 아닌 실험 속도원의 설정 변경입니다.

DCT 감속비 표시는 선택한 목표 단의 기계 톱니 비율입니다. 클러치 슬립·교대 중에는 엔진 RPM ÷ 최종 출력 RPM이 이 값과 다를 수 있습니다. 별도 `kinematicInputOutputRatio` 필드가 실제 엔진/출력 속도비를 제공합니다.

같은 입력축의 단을 건너뛰면 그 클러치를 먼저 열고 중간 시점에 선택 기어를 바꾼 뒤 다시 결합합니다. 이 경우 토크 단절을 보여 줍니다. 전진↔후진, 중립 전환에서는 클러치 교대를 겹치지 않습니다. 실제 mechatronics·유압·동기화 지연·마찰 용량·열·엔진 토크 제어는 생략합니다.

## CVT · 가변 풀리와 벨트

미끄럼 없는 개방 벨트에서 `주동 RPM × 주동 반지름 = 피동 RPM × 피동 반지름`입니다. 감속비는 `피동 반지름 ÷ 주동 반지름`입니다. 두 풀리의 축간 거리 C는 0.24m, 1:1 접촉 반지름은 각각 0.067m, 벨트 길이는 `2C + 2π × 0.067`m입니다. 감속비 0.45–2.8에서 다음 길이를 유지하도록 접촉 반지름을 수치적으로 구합니다.

`L = 2√(C² − Δr²) + π(r1+r2) + 2Δr·asin(Δr/C)`

두 직선 접선과 실제 감김 호를 합한 길이입니다. 반지름의 합만 고정하면 축간 거리가 일정할 때 벨트 길이가 미세하게 바뀌므로 그 근사를 사용하지 않습니다. 벨트 선속도는 부호가 있는 m/s로 계산합니다. 후진은 벨트를 교차시키는 대신 상류의 단순화한 방향 선택부가 두 풀리의 회전을 함께 반전합니다. 금속 벨트 장력·미끄럼·마찰 한계·탄성·유압·발진 기어·토크컨버터는 생략합니다.

## AT · 토크컨버터와 유성기어

선기어 Ns=30, 링기어 Nr=78, 플래닛 Np=24를 사용합니다. `Nr = Ns + 2Np`이며 세 플래닛을 균등 배치할 수 있는 톱니 수 구성입니다. Willis 구속식은 다음과 같습니다.

`(Ns+Nr) × 캐리어 RPM = Ns × 선기어 RPM + Nr × 링기어 RPM`

플래닛의 세계 좌표 자전 RPM은 `캐리어 RPM − Ns/Np × (선기어 RPM − 캐리어 RPM)`입니다. 화면의 플래닛은 캐리어 아래에 놓여 공전하므로, 플래닛 개별 회전에는 캐리어 RPM을 뺀 상대 RPM을 적용합니다.

| 원리 모드 | 입력 | 고정 | 출력 | 기어 감속비 |
| --- | --- | --- | --- | --- |
| 1단 | 선기어 | 링기어 | 캐리어 | 3.6 |
| 2단 | 링기어 | 선기어 | 캐리어 | 108/78 |
| 3단 | 선·링·캐리어 직결 | 없음 | 캐리어 | 1 |
| 4단 | 캐리어 | 선기어 | 링기어 | 78/108 |
| R | 선기어 | 캐리어 | 링기어 | -2.6 |

**이 표는 유성기어 하나의 연결 원리를 비교하는 교육용 포트 전환입니다.** 실제 양산 4단 자동변속기에서 단마다 입력축과 출력축 연결을 이렇게 옮기는 구조를 재현한 것이 아닙니다. 양산 AT는 복수의 유성기어셋·클러치·브레이크를 조합합니다.

토크컨버터는 펌프를 엔진 RPM, 터빈을 `(1 − 지정 슬립) × 엔진 RPM`으로 둡니다. 잠금 상태에서는 펌프=터빈 RPM입니다. 전달 토크비를 1로 두어 슬립 손실을 명확히 계산하며 스테이터의 유체 토크 증폭·발진 성능은 예측하지 않습니다. 중립이면 터빈은 돌 수 있으나 유성기어 입력 경로는 분리됩니다. 기어셋의 직결 클러치와 토크컨버터 잠금은 별개의 기능입니다.

## eCVT · 동력분할 하이브리드

초기형 입력분할 대표 구조처럼 엔진을 캐리어, MG1을 선기어, MG2와 최종 출력을 링기어에 직접 연결합니다. 벨트 CVT와 다른 구조입니다. 실제 후대 변속기의 MG2 추가 감속기·복합 기어셋은 생략합니다.

엔진 RPM과 MG1 RPM을 지정하면 Willis 식으로 링 RPM을 구합니다. 이상적인 유성기어의 준정적 반력 관계에 따라 엔진 토크 Tc 중 MG1 반력 토크는 `−Tc × Ns/(Ns+Nr)`, 링 전달 토크는 `Tc × Nr/(Ns+Nr)`입니다. 엔진 동력은 회전수에 따라 MG1과 링으로 나뉩니다. MG2 지정 토크를 링 전달 토크에 더합니다. 링 RPM이 0이어도 정적 토크는 있을 수 있지만 축 동력은 0입니다.

표시 부호는 다음과 같습니다.

- MG1 kW 양수: 기계 동력을 받아 발전. 음수: 전기를 소비해 기계 동력을 공급.
- MG2 kW 양수: 링에 기계 동력 공급. 음수: 링에서 받아 회생.
- 배터리 kW 양수: 방전. 음수: 충전.
- 출력 kW 양수: 출력축 구동. 음수: 출력축이 시스템에 동력을 공급.

MG1·MG2의 모터와 인버터를 합친 예시 효율은 각각 94%입니다. 발전할 때 전기 출력은 기계 입력×효율, 구동할 때 전기 입력은 기계 출력÷효율입니다. 배터리 순전력은 `MG2 전기 요구 − MG1 전기 생성`으로 구합니다. 기어 역구동에서는 출력축으로 들어오는 동력에 효율을 적용하는 방향을 반전해 음의 손실이 발생하지 않게 합니다.

`전체 순입력 kW = 엔진 kW + 배터리 kW`

`전체 순입력 kW − 출력축 kW = 기계 손실 + MG1/MG2 전기 손실`

이 수지는 MG1 역회전·회생·출력 역회전·전력 순환에도 성립합니다. 지정 조건을 유지하는 속도원과 모터가 있다고 가정하므로 실제 운전 가능한 배터리 SOC·전압·전류·모터 토크/회전수 제한을 판단하지 않습니다. 엔진 토크·MG2 토크를 독립 조절하면서 출력 RPM을 일정하게 유지하는 실험 조건입니다.

## 회전·하중 상세 관측값

스냅샷의 `detail`은 위 정속 모델에서 계산한 관측값입니다. 기존 설정·회전·출력 계산을 유지하면서 **회전 중인 부품과 하중을 전달하는 부품**, **정지한 부품의 반력과 에너지 손실**을 구분합니다. 차량 가속, 마찰 용량, 접촉 응력, 냉각·온도를 추가로 해석하지 않습니다. 토크가 있어도 RPM이 0이면 동력과 슬립 발열률은 0일 수 있습니다.

| 필드 | 의미와 단위 |
| --- | --- |
| `outputLoadTorqueNm` | 출력축에 외부 부하가 가하는 반작용 토크. `−outputTorque`, N·m. eCVT 역구동에서는 외부가 동력을 넣는 토크가 될 수 있음 |
| `slipLossKW`, `mechanicalLossKW`, `electricalLossKW` | 기존 손실 수지를 분리한 kW. 합은 전체 손실이며 기계 손실은 개별 접촉이 아닌 예시 효율에 의한 합계 |
| `powerBalanceResidualKW` | `순입력 − 출력 − 전체 손실`. 계산 오차 확인용 kW |
| `temperatureSolved` | 항상 `false`. kW는 발생률이며 온도·축적 열량·안전 한계가 아님 |
| `couplings[]` | 클러치 또는 등가 컨버터의 양쪽 RPM, 전달 토크, 회전차와 슬립 발열률 |
| `powerPaths[]` | 각 경로·단계의 부호 있는 입력/출력 동력과 비음수 손실 |
| `mesh[]` | 맞물림의 톱니 통과 빈도 Hz, 상대 RPM, 토크 전달 유무 |
| `idealPlanetaryTorques` | 손실 없는 유성기어에 외부에서 가하는 선·링·캐리어 토크와 고정 반력. 적용할 수 없으면 `null` |
| `belt` | CVT 감김각, 직선 접선 길이, 순환 빈도, 이상 접선력. 다른 형식은 `null` |

### 클러치 회전차와 발열률

각 `couplings` 항목은 `id`, `label`, `inputRpm`, `outputRpm`, `slipRpm`, `transmittedTorqueNm`, `engagement`, `heatKW`, `state`를 제공합니다. `slipRpm = inputRpm − outputRpm`, `heatKW = 전달 토크 × slipRpm × 2π / 60000`입니다. `state`의 `open`은 해당 전달 경로가 분리됨, `slipping`은 회전차가 있는 결합, `locked`는 잠금 상태, `synchronous`는 양쪽 속도가 같지만 완전 잠금을 지정하지 않은 상태입니다. 정지한 유체 컨버터를 속도가 같다는 이유로 잠금 상태라고 표시하지 않습니다.

MT 중립에서도 클러치 자체는 닫혀 입력축을 돌릴 수 있습니다. 이때 기어 출력 경로가 열려 전달 토크·발열은 0입니다. DCT는 두 클러치를 각각 계산합니다. 6단에서 다음 5단을 미리 선택한 열린 A축은 엔진보다 빠를 수 있으나 전달 토크가 0이므로 음의 발열을 만들지 않습니다. 변속 중에도 두 경로의 발열을 합하면 기존 클러치 손실과 같습니다.

CVT의 `reverse-unit` 관측은 방향 선택 앞의 **등가 발진 결합**입니다. 후진 풀리의 부호를 뒤집은 속도 크기를 사용해 엔진과 비교하므로, 방향 반전을 마찰 슬립으로 잘못 계산하지 않습니다. 특정 전·후진 클러치 팩의 내부 면 속도를 뜻하지 않습니다. AT 컨버터는 기존 토크비 1.0 가정의 두 축을 비교하며 중립에서는 유성기어 입력으로 전달하는 부하를 0으로 둡니다.

`powerPaths`의 MT·DCT·CVT·AT 경로는 입력·출력을 합하면 전체 동력과 같습니다. eCVT는 `mg1`의 기계→전기, `mg2`의 전기→기계, `ring`의 합성 기계→최종 출력 세 단계입니다. eCVT의 단계별 **입력 또는 출력을 단순 합산하면 내부 순환 동력을 중복 계산**합니다. 모든 형식에서 단계별 `lossPowerKW` 합은 전체 손실과 같습니다. 발전·역구동에서도 부호 있는 `입력 − 출력 = 손실`을 유지합니다.

### 톱니 통과 빈도와 유성기어 반력

`mesh.frequencyHz = 잇수 × |상대 RPM| / 60`입니다. MT·DCT에서는 고정 축 기준 기어 RPM을 사용하고, 유성기어는 캐리어에 대한 선·링의 상대 RPM을 사용합니다. 선-플래닛과 링-플래닛의 빈도는 같으며, 유성기어가 전체 직결로 함께 회전할 때는 0입니다. 후진의 두 맞물림은 18T 아이들러를 통해 같은 빈도를 가지므로 하나의 후진 관측 항목으로 제공합니다. `partIds`는 관측 항목과 관련된 선택 가능한 부품 ID입니다. `loaded`는 해당 경로가 0이 아닌 토크를 전달한다는 표식이며 개별 톱니 접촉 하중이나 소음·진동 해석 결과가 아닙니다. 부하가 없는 상시 맞물림 기어도 0이 아닌 빈도로 회전할 수 있습니다.

이상적인 유성기어의 외부 토크 벡터는 `k × [Ns, Nr, −(Ns+Nr)]`입니다. 입력 포트 토크에 맞춰 k를 정하면 세 토크의 합과 세 포트 동력의 합이 각각 0입니다. AT에서는 고정 부품에 필요한 외부 토크를 `holdingTorqueNm`으로 제공합니다. 고정 브레이크가 큰 반력을 내더라도 해당 RPM이 0이므로 `holdingPowerKW`는 0입니다. **이는 유성기어 자체의 이상 반력**이며 기존 기계 효율 손실을 적용한 실제 케이스 반력 또는 브레이크 용량 설계값이 아닙니다. AT 3단 전체 직결은 내부 치면·잠금부의 토크 분담을 결정할 수 없어 `null`을 반환합니다. 중립도 `null`입니다. eCVT의 세 포트 토크는 엔진·MG1 반력·링 전달 토크의 이상 관계이며 MG2 토크는 기어셋 뒤 링 출력에 합쳐집니다.

### CVT 감김각과 이상 접선력

`α = asin((r2 − r1)/C)`일 때 주동 감김각은 `π − 2α`, 피동 감김각은 `π + 2α`이며 각도 필드는 도 단위입니다. 직선 접선 하나의 길이는 `√(C² − (r2 − r1)²)`m입니다. 양쪽 접선과 감김 호의 길이를 합하면 기존 고정 벨트 길이를 재현합니다. `circulationHz = |벨트 선속도| / 벨트 길이`는 벨트 표식 하나가 한 바퀴 도는 빈도입니다.

`tangentialForceN = 방향 부호 × 전달 입력 토크 / 주동 반지름`으로 이상 접선력을 계산합니다. `접선력 × 벨트 선속도 / 1000`은 슬립 결합 뒤 기계 동력과 같고, 접선력×피동 반지름은 기계 효율 적용 전 이상 출력 토크입니다. 이 관측값은 금속 벨트 내부의 장력·압축력 분포, 풀리 압착력 또는 마찰 전달 한계를 계산하지 않습니다. `tensionSolved`, `tractionLimitSolved`는 모두 `false`입니다.

검증은 `tests/detail-model.test.mjs`에서 다섯 형식의 모든 선택 단, 중립·후진·정지·무부하, DCT 교대·재선택·중단, CVT 전 감속비 양끝, eCVT 발전·회생·출력 정지 조건의 경로별 손실과 토크·동력 수지를 검사합니다.

## 실제 부품을 보여 주는 해부 구조

기어만 떠 있는 도식 대신 축을 지지하는 베어링, 축 오일 씰, 클러치 작동부, 오일 저장부와 윤활·냉각 경로를 함께 표시합니다. 이 추가 부품은 **위 회전·토크·동력 계산을 바꾸지 않는 구조 관찰용 형상**입니다. 오일 입자의 개수·속도·선 굵기는 유량·압력·온도·열 발생량을 뜻하지 않습니다. 펌프의 추가 부하나 개별 베어링 마찰 손실을 별도로 계산하지 않으며 기존 예시 기계 효율을 그대로 사용합니다.

| 형식 | 선택한 대표 내부 구조 | 오일 표시의 의미 |
| --- | --- | --- |
| MT | 건식 마찰 디스크, 압력판, 다이어프램 스프링, 릴리스 베어링·포크, 축 베어링·씰 | 기어 오일 섬프에서 기어가 튀긴 오일로 윤활. 유압 밸브바디·펌프·필터를 추가하지 않음 |
| DCT | 습식 다판 두 클러치, 중공·내부 입력축, 기계식 펌프, 흡입 필터, 메카트로닉스, 냉각기 | 클러치 작동·오일 냉각·기어와 베어링 윤활의 대표 경로 |
| CVT | 전진 습식 클러치, 후진 마찰 작동부, 가변 풀리 피스톤, 펌프·스트레이너·밸브바디 | 풀리 압착·위치 조절과 방향 선택부 작동·윤활의 대표 경로 |
| AT | 습식 변속 팩, 고정 브레이크, 컨버터, 엔진 측 기계식 펌프, 스트레이너·밸브바디 | 클러치·브레이크·컨버터 작동과 기계부 윤활의 대표 경로 |
| eCVT | 유성기어, MG1·MG2, 축·모터 베어링·씰, 오일 저장부·스트레이너·냉각부 | 기어·베어링 윤활과 모터 냉각. 변속 클러치·변속용 유압 밸브바디 없음 |

MT에서는 **마찰 디스크가 입력축 RPM**으로 돌고 압력판·다이어프램은 엔진 RPM으로 돕니다. 릴리스 베어링의 다이어프램 접촉 링은 엔진 RPM, 지지부와 포크는 회전하지 않는 대표 선압 구조입니다. 분리 작동 위치는 `1 − 클러치 결합률`로 표시하며 실제 스트로크·스프링 하중을 계산하지 않습니다. 기어 오일과 건식 클러치 공간은 구분합니다.

DCT 장면은 **습식 대표형**을 선택했습니다. 모든 DCT가 습식인 것은 아닙니다. Volkswagen의 공식 비교 자료처럼 건식 DCT에서는 클러치 냉각용 필터·오일 냉각기·가압 경로가 줄어들고 유압 회로가 분리될 수 있습니다. 이 앱의 홀수·짝수·후진 경로와 기어비는 공개된 교육용 선택이며, 특정 DSG 차종의 모든 연결을 그대로 재현한 조립도는 아닙니다.

CVT의 후진 작동부는 양산 형식에 따라 클러치 또는 고정 브레이크를 사용합니다. 장면은 대표 마찰 팩으로 방향 선택 기능을 보여 주며 상세 전·후진 유성기어와 유압 회로를 계산하지 않습니다. 풀리 피스톤의 위치는 벨트 접촉 반지름에 맞추어 표시합니다. AT 습식 팩 역시 원리 모드의 연결 역할을 보여 주며 특정 양산 4단 자동변속기의 팩 개수·유로를 재현하지 않습니다.

DCT·CVT·AT의 표시 펌프는 엔진 측 기계 구동 대표형이며 엔진 RPM을 사용합니다. 실제 전달 동력이 없는 중립에서도 엔진이 회전하면 펌프와 오일 경로를 표시할 수 있습니다. eCVT의 펌프는 **회전수 미지정 대표 냉각·윤활 부품**이며 특정 구동 방식이나 임의의 전동 펌프 RPM을 지정하지 않습니다. 실제 하이브리드 변속기마다 오일 펌프 구동·모터 냉각 방식은 달라집니다.

베어링 묶음은 하나의 RPM이 없습니다. 각 내륜은 해당 축의 RPM, 하우징에 고정된 외륜은 0입니다. `bearingRpm` 필드는 축별 내·외륜 속도를 제공하며 베어링 집합의 `partRpm.bearings`는 0인 비단일축 표식입니다. eCVT 모터 회전수와 베어링 속도는 위 동력분할 관계에 따른 값을 그대로 사용합니다.

부품 `category`는 `gears`, `clutches`, `bearings`, `lubrication`, `housing`, `electrical`, `input` 중 하나입니다. 카테고리로 관찰 대상을 골라도 부품의 실제 계산 연결과 동력 수지는 바뀌지 않습니다.

### 조립 절개 화면과 저장 파일

공식 실물 절개 자료에서 확인한 주조 케이스·가공 강철·드럼·베어링의 특징을 참고해 기본 화면을 조립 절개 상태로 표시합니다. 케이스의 절개·닫힘·숨김, 절개 창 크기와 분해 간격은 관찰 방법이며 모델의 축 연결·잇수·속도·동력 계산을 바꾸지 않습니다. 실제 참조 이미지와 적용 범위는 [cutaway-reference.md](cutaway-reference.md)에 기록합니다. 원본 사진·회사 CAD·이미지 텍스처를 제품에 포함하지 않습니다.

새 `housingMode`가 없는 기존 1.0/1.1 저장 파일은 조립 절개 기본 화면으로 옮깁니다. 옛 케이스 표시값이 0인 파일은 숨김 선택을 유지합니다. 엔진·변속기 설정과 나머지 표시 선택은 보존합니다. DCT의 축방향 기어 순서를 조립 가능한 중공축 배치로 바꾸어도 홀수 A/짝수·후진 B의 계산과 각 기어 ID·잇수쌍은 유지합니다. AT는 단일 유성 원리 모형, eCVT는 기존 입력분할 대표 연결을 그대로 사용합니다.
